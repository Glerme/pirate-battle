## Limitations
- Hardware GPU via ANGLE (`--use-angle=vulkan`) in new headless mode; rAF is vsync-capped to the display refresh, so avg FPS tops out at the monitor rate (see WebGL renderer above). Numbers are from one machine, not a certified reference device.
- Frame times are rAF deltas inside the page, so they include the bot's `page.evaluate` polling overhead.
- The bot is not a player: entity counts depend on how well it kills enemies (with the HP knob it cannot die, so load may differ from a human match). Single machine, single run; a ~10 s DevTools trace is in [trace.json.gz](trace.json.gz) (gunzip, then load in Chrome DevTools → Performance or ui.perfetto.dev).
- Pixi texture count is `renderer.texture.managedTextures` (GPU-uploaded textures); atlas textures stay cached between matches by design.
